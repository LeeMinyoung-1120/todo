# Todo 앱 만들기

## 목표
1. 프론트엔드, 백엔드 프로젝트 생성
2. Mongo DB 와 연동
3. 기본적인 CRUD 기반 REST API 작성

## 담당자
* 프론트엔드 : 이민영 <br>
* 백엔드, DB : 장한별 <br>
* 화면 설계, UI 디자인 : 박윤주 <br>

## 주요 기능
✅ Todo 기본 앱 기능
* 할 일 추가, 삭제
* 할 일 총 카운트 표시
* 할 일 목록 검색
* 할 일 목록 필터링 - 카테고리, 중요도, 완료 여부 등
* 할 일 목록 정렬 - 생성순, 마감일순, 중요도순

✅ Mongo DB 와 연계
* express.js 에서 작성된 API 호출 시 DB 에서 할 일 갱신
